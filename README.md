This game is reverse engineered from the Playstation 2 ISO file. it keeps the originalbasic working of all the assets in the game. I do not own the copyright of the game.
Music and sounds are scraped from the ISO, textures where recovered and upscaled as necessary to improve quality.
A dash mechanic was created for the characters.
A new character was created with a personal 3D model, animation sprites and special effects. Its unique ability can deflect shots back to the enemies.
A menu was created allowing to remap buttons, control sound and music volume and change between 3 difficulty settings.
A selector was added in the menu to allow for random spawning of allies and of the initial group.
A local save setting with 3 slots was implemented in the game, allowing a player to continue from any stage they left.
Local co-op is implemented.
Stage selecting is implemented.
An easter egg was implemented.
New sprites were added for the necessary menus.
Browser and mobile play is implemented.
Shaders are implemented.
